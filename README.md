# Home-SIEM-Lab-Project
In this project, I will create a home SIEM (Security Information and Event Management) lab using Wazuh in order to practice and gain experience in investigating a network's security.

### What is SIEM?

A Security Information and Event Management (SIEM) system is a cybersecurity solution that monitors and analyses large amounts of information and data from the applications, devices, servers and users in an organisation's network, in real time, organising all of it into a single platform. This gives a more coherent view of a network's security and allows an organisation's security operation center (SOC) to find and respond to security issues faster and more efficiently, reducing the risk of an organisation being compromised by a security breach.
